# Factorial HR
> Fast-growing European SMB all-in-one HR — broad, approachable, value-priced — but thin on Saudi/GCC statutory payroll.
> Up: [[Competitor Index]] · System: [[COMPETITORS]]

## Overview
- **Company:** Factorial (Barcelona, Spain), founded 2016; VC-backed, aggressive growth across Europe and LATAM. 🔄 verify latest funding/valuation.
- **Product:** All-in-one HR platform for SMBs — core HR, time tracking & shifts, time off, documents & e-sign, expenses, performance, ATS, and payroll (native in some countries, integrations elsewhere).
- **Target Market:** European (and expanding LATAM) small and mid businesses, commonly ~10–200 employees.
- **Pricing:** Modular per-employee-per-month with plan tiers + add-on modules; often positioned as affordable vs incumbents. 🔄 verify current plan/module pricing.
- **Strengths:** Breadth for the price, modern clean UI, quick self-serve setup, strong time/shift + time-off + document management for SMBs, growing ecosystem.
- **Weaknesses:** Depth is uneven module-to-module (some feel newer/thin); payroll maturity varies sharply by country; not GCC/KSA-localized; no Arabic/RTL; reporting/analytics not enterprise-grade.
- **Positioning:** "One affordable app to run all of HR for a growing SMB" — the value-led all-in-one.

## UX Notes
- **Navigation:** Modern, clean module-based left nav; approachable for non-HR admins.
- **Search:** Present; product breadth makes it useful but not a Linear-grade command palette.
- **Dashboard:** Friendly overview with pending tasks/approvals; SMB-appropriate.
- **Configuration:** Self-serve settings + custom fields; low barrier, medium ceiling.
- **Automation:** Reminders + some no-code automations; lighter than a true engine.
- **Performance:** Generally responsive SMB-scale web app.
- **Accessibility:** Modern web standards 🔄 verify formal conformance.
- **Dark Mode:** 🔄 verify availability.
- **Arabic Support:** Not a target locale; no first-class RTL/Arabic. Contrast [[Arabic RTL]].
- **Mobile UX:** Strong for employee tasks (clock-in, time off, expenses, docs).

## Things we love
- True all-in-one breadth at an SMB-friendly price.
- Document management + e-signature done well for small teams.
- Expense capture and time/shift tracking that employees actually use on mobile.

## Things we hate
- Payroll depth is country-lottery; no statutory engine we can rely on for KSA.
- Uneven module maturity — breadth over depth in newer areas.
- Not built for RTL/Arabic or GCC compliance.

## Customer complaints
Recurring review themes (G2/Capterra-style): support responsiveness slipping as they scale; some modules feel half-baked or change frequently; occasional bugs/instability with rapid releases; payroll/localization gaps outside core markets; reporting less flexible than hoped. ## Workflows
- Payroll: Time + absences + variable pay collated → run/export to native or integrated payroll. Contrast [[Payroll Engine]].
- Attendance/Leave: Clock-in/shifts + time-off requests → approvals → feeds pay. Cf. [[Attendance]].
- Recruitment: Career site → ATS pipeline → hire into core HR. (SanadHR: [[ROADMAP]].)
- Approvals: Time off / expenses / documents approval chains. Cf. [[Request Center]].
- Reports: Custom SMB reports + overview analytics. Cf. [[Reports]].

## Ideas worth stealing
- Breadth-at-value packaging: make an all-in-one feel affordable and un-intimidating for SMBs.
- Document + e-signature as a core, everyday module — enrich [[Documents]].
- Frictionless mobile clock-in/time-off/expenses to drive [[ESS]] adoption.
- Expense capture UX to model our [[Expenses]] intake.

## Improvements we can make
- **Simpler:** Match Factorial's approachable all-in-one, but with one coherent [[Design System]] instead of uneven module feel.
- **Faster:** Self-serve setup + instant tenant bootstrap.
- **More configurable:** Go beyond custom fields to a real [[Master Data Engine]] and [[Configuration over Hardcoding]] for Saudi rules.
- **More automated:** A genuine visual [[Workflow Engine]] vs reminders-plus-a-few-automations.
- **More scalable:** [[Immutable Ledger]] payroll that's reproducible and audit-proof, not country-lottery.
- **More beautiful:** Keep the clean modern feel, deliver it RTL-first via [[Arabic RTL]].
