# ZenHR

> The clean-UX, well-loved GCC/Levant HR SaaS — praised for support and localized GOSI/WPS handling.
> Up: [[Competitor Index]] · System: [[COMPETITORS]]

## Overview
- **Company:** ZenHR — cloud HR SaaS with strong presence across GCC + Levant (Jordan/Amman roots, KSA + UAE + broader MENA reach). Positioned as approachable, localized, SMB→mid HR. 🔄 verify HQ/funding specifics.
- **Product:** All-in-one cloud HRMS: core HR, payroll, attendance/leave, self-service, recruitment, performance — with localized compliance per country (GOSI, WPS, End-of-Service).
- **Target Market:** SMB and mid-market across GCC/Levant; companies wanting clean, localized HR without enterprise complexity.
- **Pricing:** Per-employee-per-month SaaS tiers; SMB-friendly. 🔄 verify exact tiers/PEPM.
- **Strengths:** Clean, approachable UX; frequently praised customer support/onboarding; solid multi-country localization (GOSI/WPS/EOS); good ESS + mobile; balanced breadth for SMB.
- **Weaknesses:** Payroll is reliable but not deeply transparent/reproducible; configurability is friendly but bounded; analytics/reporting mid-tier; not as compliance-obsessed as [[Jisr]] in pure KSA depth; performance/recruitment modules are adequate not standout.
- **Positioning:** "Localized HR that's genuinely pleasant to use — with support that answers." UX + service as the moat.

- **Configuration:** Approachable settings; guided.
- **Automation:** Basic rule-based approvals + reminders.

## Things we love
- Genuinely clean, approachable UX for SMB.
- Support/onboarding reputation is a real differentiator.
- Balanced localization across GCC/Levant.

## Things we hate
- Payroll transparency/reproducibility not first-class.
- Configurability is friendly but bounded — power users plateau.
- Reporting/analytics mid-tier.

## Workflows
- **Payroll (+ WPS/GOSI):** Salary setup → run → GOSI + WPS/SIF outputs → bank routing. Reliable, not line-item-traceable.
- **Attendance/Leave:** Geofence/biometric → shifts → leave balances → payroll feed.
- **Recruitment:** Requisition → pipeline → hire → onboard.
- **Approvals:** Clean multi-level with notifications.
- **Reports:** Good standard set; custom mid-tier.

## Ideas worth stealing
- Onboarding + support as a product feature, not a cost center.
- Approachable, low-learning-curve UX that SMB admins actually enjoy.
- Clean approval + notification patterns.

## Improvements we can make
- **Simpler:** Match their approachability while going deeper.
- **Faster:** Modern app-shell speed.
- **More configurable:** True [[Configuration over Hardcoding\|no-code]] via [[Master Data Engine]] vs bounded config.
- **More automated:** Visual [[Workflow Engine]] beyond rule-based approvals.
- **More scalable:** [[Financial Calculation Engine]] + [[Immutable Ledger]] payroll transparency.
- **More beautiful:** [[Design System]]-grade polish + superior [[Arabic RTL]].
