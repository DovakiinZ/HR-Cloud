# Personio
> The European SMB→mid HR leader — strong core HR, applicant tracking, approvals, and DACH/EU compliance — but no Saudi/GCC statutory depth.
> Up: [[Competitor Index]] · System: [[COMPETITORS]]

## Overview
- **Company:** Personio SE & Co. KG (Munich, Germany), founded 2015; one of Europe's most valuable HR-tech unicorns. 🔄 verify latest valuation/funding.
- **Product:** "People Operating System" — core HR, absence & time, recruiting (ATS), performance & development, approvals/workflows, documents, reporting, and payroll (native Personio Payroll in select markets + integrations elsewhere).
- **Target Market:** European SMB and mid-market (roughly 10–2,000 employees), with particular strength in the DACH region (Germany, Austria, Switzerland).
- **Pricing:** Per-employee-per-month, plan tiers + add-ons; annual contracts; enterprise-ish sales motion vs pure self-serve. 🔄 verify current tiers/pricing.
- **Strengths:** Solid core-HR data model, strong ATS/recruiting, flexible approval workflows, robust document management, European (esp. German) compliance familiarity, mature reporting for the tier.
- **Weaknesses:** Can feel rigid/config-heavy to set up; UI functional over delightful; payroll native only in some markets; not GCC/KSA-localized; no Arabic/RTL; pricier than value players like [[Factorial HR]].
- **Positioning:** "The all-in-one People OS for European SMB/mid-market that takes compliance seriously."

**Saudi/GCC gaps:** No GOSI, no WPS/Mudad file generation, no Qiwa, no Article 84/85 [[End of Service]] settlement, no Hijri calendar, no Arabic/RTL. Compliance strength is European (German/EU) — not transferable to Saudi labor law.

## UX Notes
- **Navigation:** Structured, module-based; more "capable admin tool" than consumer-delight.
- **Search:** Functional global search; not a keyboard-first command palette.
- **Dashboard:** Task/approval-oriented home + reporting insights.
- **Configuration:** Deeply configurable (roles, workflows, attributes, documents) — powerful but a real setup investment.
- **Automation:** Configurable approval workflows + event automations; strong for the tier.
- **Performance:** Solid at SMB/mid scale.
- **Accessibility:** European enterprise expectations 🔄 verify formal conformance.
- **Dark Mode:** 🔄 verify availability.
- **Arabic Support:** Multi-language European focus; no first-class RTL/Arabic. Contrast [[Arabic RTL]].
- **Mobile UX:** Competent for self-service and approvals.

## Things we love
- Approval workflows and role-based permissions that are genuinely configurable.
- Document management with e-sign and a compliance/retention mindset.
- A strong, integrated ATS inside the core HR suite.

## Things we hate
- Setup can feel heavy/rigid — configurability with a learning curve.
- UI is functional over delightful (vs Gusto's warmth).
- No GCC localization, no Arabic/RTL; European payroll only.

## Customer complaints
Recurring review themes (G2/Capterra/Trustpilot-style): steep/effortful initial configuration; support and account-management responsiveness criticized as they've scaled; pricing and contract/renewal friction; some rigidity when a process doesn't fit Personio's model; payroll limited outside core markets. (Themes only — no invented quotes/numbers.)

## Feature requests
Easier/faster setup; broader native payroll; more flexible reporting; better pricing transparency; deeper expenses; more delightful day-to-day UX; more automation beyond approvals.

## Workflows
- Payroll: Master data + absences + variable pay → preliminary payroll → native run or export to payroll partner. Contrast [[Payroll Engine]].
- Attendance/Leave: Absence + attendance tracking → approvals → feeds preliminary payroll. Cf. [[Attendance]].
- Recruitment: Career page → ATS pipeline → offer → hire into core HR. (SanadHR: [[ROADMAP]].)
- Approvals: Configurable multi-step approvals across HR events. Cf. [[Request Center]].
- Reports: Flexible custom reports + analytics over the HR data model. Cf. [[Reports]].

## Ideas worth stealing
- Configurable, role-based approval workflows as a first-class citizen — inform [[Workflow Engine]] and [[Request Center]].
- Compliance-minded document management (e-sign + retention) — enrich [[Documents]].
- A native ATS integrated with core HR — a [[ROADMAP]] direction.
- Granular permission roles that map to real HR org structures — inform [[Access Management]].

## Improvements we can make
- **Simpler:** Deliver Personio-grade configurability without the heavy setup — sensible Saudi defaults via [[Master Data Engine]].
- **Faster:** Instant tenant bootstrap + guided KSA onboarding vs long configuration.
- **More configurable:** Same power, but no-code and Saudi-aware via [[Configuration over Hardcoding]].
- **More automated:** Extend beyond approvals to a full visual [[Workflow Engine]] driving payroll/attendance effects.
- **More scalable:** [[Immutable Ledger]] payroll that's reproducible and audit-proof, not partner-export-dependent.
- **More beautiful:** Add Gusto-like warmth to Personio-like depth, RTL-first via [[Arabic RTL]] and [[Design System]].

SanadHR matches Personio's configurable-approvals and documents depth while adding a reproducible [[Immutable Ledger]] payroll on the [[Financial Calculation Engine]], native Saudi statutory coverage (GOSI/WPS/Mudad/Qiwa, [[End of Service]]), no-code [[Configuration over Hardcoding]], and first-class [[Arabic RTL]] — with warmer day-to-day UX.
